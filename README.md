# ☕ BOJIKK's Cosmic Coffee

Космическая кофейня — неоновый дизайн, парящие карточки и полная корзина заказов.

## 🚀 Функционал
- Фильтрация товаров (Кофе / Космические / Десерты)
- Корзина с добавлением, удалением, подсчётом суммы
- Сохранение корзины в localStorage
- Адаптивная вёрстка
- Анимированные звёзды на фоне
- Стеклянные карточки (glassmorphism)

## 🛠 Технологии
HTML5, CSS3 (Flexbox/Grid/Keyframes), JavaScript ES6

## 📁 Структура
- `index.html` — разметка
- `style.css` — стили и анимации
- `script.js` — логика корзины и фильтрации

## 🎯 Для портфолио
Проект демонстрирует нестандартный дизайн, анимации, работу с DOM и localStorage.
